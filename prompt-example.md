# Пример базы знаний

Расширение не хранит тексты ответов в коде. Оно берёт их из базы знаний,
которую вы вставляете в настройки расширения целиком, одним полем.

База — это обычный текст. Куски, которые уходят клиенту дословно, размечены
блоками:

```
### БЛОК: ИМЯ_БЛОКА
Текст, который увидит клиент. Ровно этот, слово в слово.
### КОНЕЦ БЛОКА
```

Между блоками пишите правила для модели: когда блок подходит, когда нет, что
спросить раньше. Этот текст клиенту не уходит — он нужен, чтобы модель выбрала
верный блок.

Модель не пишет инструкции сама: она называет имя блока, а текст подставляет
код. Исключение одно — короткий справочный ответ (поле `answer`), и он проходит
отдельные проверки: ни пошаговых инструкций, ни ссылок, ни сумм, которых нет
в базе.

## Переменные

В блок можно подставить данные аккаунта:

```
### БЛОК: BAL_NEGATIVE
Баланс сейчас {баланс}₽, при нулевом или отрицательном доступ отключается.
Пополнить можно в приложении: внизу «Кабинет», сверху кнопка «Пополнить».
### КОНЕЦ БЛОКА
```

Доступны `{баланс}`, `{тариф}`, `{списание}`, `{сумма}`, `{дни}`. Если данных
нет, код не отправит такой блок с дырой в тексте: он сам сходит за данными
в панель, а если и там пусто — отдаст обращение человеку.

## Темы

Выбирать из сотни блоков модель не умеет — берёт привычные. Поэтому база
делится на темы, и выбор идёт в два шага: сначала тема, потом блок внутри неё.
Тема помечается комментарием перед разделом:

```
<!--ТЕМА:подключение-->
```

## Небольшой пример целиком

```markdown
<!--ТЕМА:подключение-->
## Суть: не подключается

Начинайте с перезагрузки только если клиент её ещё не делал. Если в переписке
перезагрузка уже была — это пройденный шаг, возвращаться к нему нельзя.

### БЛОК: FIX_REBOOT
Перезагрузите, пожалуйста, ваше устройство.
### КОНЕЦ БЛОКА

Не помогло — просите снимок главного экрана приложения. По нему видно сразу:
включён ли белый список, какая страна, есть ли ключ.

### БЛОК: ASK_SCREENSHOT_MAIN
Скиньте пожалуйста скриншот главного экрана из приложения
### КОНЕЦ БЛОКА

<!--ТЕМА:ключи-->
## Суть: где взять ключ

### БЛОК: INSTR_GET_KEY
Откройте личный кабинет, выберите тариф и скопируйте ключ.
Скопировали — откройте приложение, оно само предложит его добавить.
### КОНЕЦ БЛОКА

<!--ТЕМА:устройства-->
## Суть: удалить лишнее устройство

Основной кабинет удалить нельзя, дополнительный можно. Прежде чем отвечать,
разберитесь, что именно клиент хочет убрать: здесь легко посоветовать не то.

### БЛОК: INSTR_DELETE_CABINET
Основной кабинет удалить нельзя, он привязан к профилю. Но задачу решить можно:
удалите дополнительный кабинет, а ключ от основного вставьте в приложение на
новом устройстве. Ключ не привязан к устройству, поэтому он там заработает.
### КОНЕЦ БЛОКА
```

## Сторож на обрезанную базу

Расширение считает блоки при сохранении настроек и при каждом запуске. Если их
меньше порога из настроек — бот не стартует и пишет об этом в Telegram.

Сторож появился не на пустом месте: однажды при вставке доехала только «голова»
базы, из сотни блоков осталось семь, и на любую жалобу бот отвечал
пересозданием ключа — других блоков у него просто не было. Заметили не сразу.
